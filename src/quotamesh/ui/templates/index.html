Each target is a provider + model + key choice. “Provider pool” tries matching enabled credentials by priority. QuotaMesh keeps your saved order; it never ranks or invents equivalent models.

Templates change the form only. Mixed-plan pools become explicit key targets to preserve free-first order. Inspect and save the result; runtime always uses your saved order.

Skipped keys do not consume attempts. The gateway does not sleep through cooldowns or retry the same key/model. Changes take effect when you save.
